В этом уроке мы научились создавать бота, который получает update от телеграма через webhook и обрабатывает его.

В качестве домашнего задания вы должны сделать:
1. Установить cloudflared tunnel для создания временного url для тестирования вашего бота.
2. Воспроизвести пример из урока и проверить его работу.
3. Создать структуру
/start — описание клуба
inline кнопки которые имитируют работу приложения. 
Кнопки:
Вступить в клуб (вторая менюшка)
Зачем тебе в клуб (сообщение с описанием преимуществ вступления в клуб)
Поддержка (ссылка на ваш аккаунт)
Отзывы (ссылка на канал с отзывами в телеграме)

2 менюшка:
Оплатить картой РФ
Оплатить зарубежной картой
